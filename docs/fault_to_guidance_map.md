# 결함 → 지침 조항 매핑 규칙 (초안, Stage 0-G)

**작성일:** 2026-10-18 · **성격:** 본 프로젝트의 **가정**(계획서 §1.3). KOSHA GUIDE P 시리즈는 TEP 공정을 설명하지 않으므로, TEP 결함 20종과 지침 조항의 연결은 "결함의 물리적 기제 → 지침 주제 → 조항"이라는 규칙으로 정의한다. 조항이 그 상황에 공학적으로 올바른 조치라는 주장이 아니라, 에이전트가 근거 검색을 시작하는 **사전 분포**이며 근거성 평가(H3)의 정답 범위다. · **입력:** `outputs/kosha_clause_index.json`(ST0-15 규칙, 28건 699조항) · **실체화:** `scripts/build_fault_guidance_map.py` → `outputs/fault_guidance_candidates.json`

## 1. 규칙

1. 결함마다 **주제**를 하나 부여한다(§2 표). 주제는 결함의 기제(피드 조성·피드 온도·반응기 냉각·응축기 냉각·피드 손실·헤더 압력·반응 속도론·밸브 고착·미공개)다.
2. 주제마다 **1차 지침**(기제를 직접 다루는 문서)과 **2차 지침**(점검·경보·인터록 같은 보조 절차)을 지정한다(§2 표).
3. 조항 후보는 지정 지침 안에서 **제목+본문 앞부분의 키워드 일치**로 뽑고, 목적·적용범위·정의 조항과 부록(사고사례·단계 서술)은 제외한다. 후보 목록은 사람이 검토해 사전등록 전에 확정한다.
4. **공통 조항**(결함과 무관하게 모든 경보에 인용 가능): P-116 5.1 문제점 도출 / 5.2.2 경보의 선정 및 우선순위 / 5.2.4 경보 설정값 / 5.2.5 지속적 관리, P-133 5.1 우회 대상·사유 / 5.2.2 정상운전 시 우회절차 / 5.2.3 긴급사항 시 우회절차(인터록 우회가 **승인·절차 없이는 금지**라는 근거 → 정의서 §3 금지 조치의 문서적 근거), P-129 계측기 점검(조항은 색인 검토 후 확정 — "센서를 먼저 믿어도 되는가"는 Layer 1 게이트와 짝을 이룸).
5. **미공개 결함 16–20은 1차 지침이 없다.** 공통 조항만 후보이며, 에이전트가 특정 조치를 제안할 근거가 부족하면 보류·추가 조회로 가야 한다 — H3("근거 없으면 조치안 없음")의 시험 구간. 디스트랙터 2건(P-44, P-22)은 어느 결함에도 배정하지 않는다.
6. 매핑은 **결함 유형 → 조항**이지 **센서 → 조항**이 아니다. 진단 집합이 여러 결함을 담으면 후보 조항은 집합의 합집합이고, 그 크기가 "추가 조회" 쪽으로 정책을 기울이는 신호가 된다(H1).

## 2. 결함 → 주제 → 지침

| 결함 | 내용 (Downs & Vogel 1993) | 유형 | 주제 | 1차 지침 | 2차 지침 |
|---|---|---|---|---|---|
| 1, 2, 8 | A/C 비율·B 조성(1,2 계단; 8 변동) | 피드 조성 | feed_composition | P-132 혼합공정, P-167 시료채취·분석 | P-179 혼합가스 폭발성, P-129 계측기 |
| 3, 9, 10 | D·C 피드 온도(3 계단; 9,10 변동) | 피드 온도 | feed_temperature | P-38 발열반응 위험, P-53 발열반응 방호 | P-129, P-116 |
| 4, 11 | 반응기 냉각수 입구 온도 | 반응기 냉각 | reactor_cooling | P-53, P-38(5.7 안전운전 한계), P-65 파열판 | P-133 인터록, P-116 |
| 5, 12 | 응축기 냉각수 입구 온도 | 응축기 냉각 | condenser_cooling | P-60 냉매·냉각설비, P-53 | P-129 |
| 6 | A 피드 손실 | 피드 손실 | feed_loss | P-18 누출 안전조치, P-52 격리, P-77 원격차단밸브 | P-58 사고대응 |
| 7 | C 헤더 압력 손실 | 헤더 압력 | header_pressure | P-18, P-65, P-159 벤트 | P-121 분리설비 운전 |
| 13 | 반응 속도론 드리프트 | 반응 | reaction_kinetics | P-38(5.x 위험확인·열량), P-53 | P-120 설계·변경 |
| 14, 15 | 냉각수 밸브 고착 | 밸브 | valve_sticking | P-77(6.3 작동장치, 6.4 페일모드, 7.2 실패요인, 7.3 정비·검사·테스트), P-129 | P-133(5.1 계기 불량 시 우회) |

신뢰도 표기(후보 확정 시 부여): **A** 기제를 직접 다루는 조항(예: 14 ↔ P-77 7.3) / **B** 같은 주제의 일반 조항 / **C** 공통 조항. 평가셋의 "참조할 조항은?" 문항 정답은 A·B에서, "해당 조항 없음" 문항은 16–20과 디스트랙터에서 만든다.

## 3. 이 매핑이 아닌 것

- TEP의 결함은 시뮬레이터 교란이고 지침은 실제 플랜트용 권고다. 연결은 유비(냉각수 온도 변화 ↔ 발열반응 냉각 상실 대비)이며, 실제 고객이면 사내 운전절차서로 대체되고 이 문서는 "어떤 절차서가 필요한가"의 질문지가 된다.
- 조항 후보의 순위는 검색(BM25+벡터+리랭커)이 정하고, 이 매핑은 ACL 사전 필터와 같은 층의 **범위 제한**으로만 쓴다(계획서 §4.4). 매핑에 없는 조항을 검색이 찾아 인용하는 것은 허용되며 근거성 평가에서 사람이 판정한다.
- 센서 기여(SHAP)와 조항의 연결은 하지 않는다.

## 4. 확정 절차

1. `python scripts/build_fault_guidance_map.py` → `docs/fault_guidance_candidates.md` 검토: 결함별 1차 후보 ≤ 8개 중 A/B 부여, 무관 후보 삭제, 누락 조항 수동 추가(색인 `clause_key`로).
2. P-129 공통 조항 확정, P-53·P-65·P-18·P-52·P-58·P-60·P-121·P-159·P-120·P-167·P-132·P-179 조항 제목 검토.
3. 확정본을 `outputs/fault_to_guidance_map.json`으로 고정(사전등록 포함, `prereg-v1`).
