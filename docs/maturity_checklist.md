# 자율성 성숙도 체크리스트 — Stage 0-H 초안

**작성일:** 2026-10-19 · **양식:** scm-control-tower-agent `maturity_checklist.md` 계승(단계 정의 → 진입·유지 조건 → 승격·강등 규칙 → 증거 → 현재 상태) · **원칙:** "Agent ≠ always act"(계획서 §1.2). 승격은 리플레이 증거로만, 강등은 운영 지표 하나로 즉시 · **구현 범위:** L1 구현, L2는 리플레이 승격 규칙만(Should), L3 미구현(문서 1장) · **갱신:** 상태 열은 Stage 종료 시 갱신, 규칙 열의 변경은 결정 로그

## 1. 단계 정의

| 단계 | 에이전트가 하는 것 | 사람이 하는 것 | 본 프로젝트 |
|---|---|---|---|
| **L0** 규칙 기반 | 고정 임계치 알림 + 고정 플레이북(공통 조항 C) | 전부 | H1 기준선 B2 |
| **L1** 조언형 | 게이트 → 탐지·진단 → 근거 → 승인 요청서. 모든 조치안이 승인점 ① | 승인·수정·거부, 실행·롤백 | **구현(Must)** |
| **L2** 승인형 | L1 + 조건 S를 모두 만족하는 조치안은 자동 발행, 예외만 승인점 ② | 일일 요약 확인, 예외 승인 | 리플레이 승격 규칙만(Should) |
| **L3** 위임형 | 운전 조건 변경까지 | 사후 감사 | 미구현. `docs/extensions.md` 1장 |

조건 S(L2 자동 발행 자격, 사전등록 §4.5 입력 기준, 전부 인과적): `p_adj_t ≤ α/2 = 0.05`(prefix-BH) ∧ `set_size == 1` ∧ `ev_AB`(A·B 등급 g ≥ τ, scoped) ∧ `gate == PASS` ∧ `drift == ok` ∧ `q_used == 0`(1차 창에서 바로 성립).

### L2 승격 규칙 (리플레이 전용, Should)

L2는 실제 운영에서 켜지 않는다. 아래 조건을 **Stage 5 리플레이 결과**로 평가해 "L2 자격 있음/없음"만 보고한다.

| # | 조건 | 기준 |
|---|---|---|
| L2-P1 | H1 통과 | 세 Δ_j CI 하한 > 0 |
| L2-P2 | H2 통과 | 실현 FDR ≤ 0.13 |
| L2-P3 | H3 통과 | hit@3 ≥ 0.80, 근거성 ≥ 0.85, 근거 없는 조치안 0 |
| L2-P4 | 조건 S 적격 제안 중 비결함 창 제안 비율(자동 발행 시 오탐률) | ≤ 0.05, 적격 제안 ≥ 200건 |
| L2-P5 | 조건 S 적격 제안의 수동 승인 세션 일치율(30건 중 S 해당분) | ≥ 0.90 (해당분 < 10건이면 "표본 부족"으로 보고) |
| L2-P6 | 조건 S 적격 제안의 결함 유형 분포 | 20종 중 ≥ 10종에서 발생(한 결함에 몰리면 자격 없음) |
